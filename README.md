# UniOrbi-SWO

یہ ایک مکمل طور پر آپریشنل زیرو نالج پرسنل ایکو سسٹم ہے۔

## ڈیپلائمنٹ
1. اپنے مقامی ماحول میں .env فائل بنائیں اور اوپر دی گئی مثال کے مطابق متغیرات درج کریں۔
2. `npm install` کمانڈ چلائیں۔
3. `npm run build` کے ذریعے پروجیکٹ کو کمپائل کریں۔

## آپریشنل گائیڈ
ڈیمو فیچرز کو ختم کر دیا گیا ہے۔ براہ کرم ڈیٹا بیس اور API کنفیگریشن کے لیے Supabase اور Stripe کا استعمال کریں۔
